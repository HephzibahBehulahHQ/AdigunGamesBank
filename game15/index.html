    Mission log

      Rules, original assets and release scope

      This is a deterministic tactical game with a local heuristic opponent. It uses no live model API. Each drone can move, fire, collect or guard once per round. End turn guards your remaining ready drones. Hard cover blocks movement and sight; guard absorbs one pulse before the next activation. Disabled wrecks do not block movement.

      Secure missions require all opponents to be disabled. Uplink missions require uncontested control at each round boundary. Recovery missions require collecting the data core and carrying it back to column 1. Losing every drone, exhausting the round budget, or losing an uplink ends the mission. Retry does not erase earlier campaign progress.

      All models, geometry, interface and game content are original to this repository. Three.js is MIT licensed. The catalog's 2,000-game target and production hardware/accessibility qualification remain unfinished. Game design and testing record.
