One bench. A sharper memory.

  1. Reveal two different covered trays. The first two bands give digits, the third gives a multiplier and the separated fourth band gives tolerance.
  2. Read the value and pattern. A successful comparison uses matching nominal resistance and tolerance.
  3. Select Store matched pair or Cover mismatched pair. Both components remain visible until you choose.
  4. Store every pair within the move budget to unlock the next challenge. A retry keeps the same layout so you can learn it.

Tab reaches each tray and command. Within the trays or focused 3D bench, use ←→↑↓ to select a tray, Enter or Space to reveal, C to store/cover and R to retry. All commands also work with visible buttons.

There is no countdown. Cover movement respects reduced-motion settings. Revealed values, text patterns and colour names make colour recognition optional.

Campaign and rendering limits

10,000 deterministic layouts progress from four pairs to twelve, with wider nominal-value ranges and smaller mistake allowances. These are procedural identification exercises, not 10,000 separately authored games.

Adaptive, 1080p and 4K select the actual WebGL drawing buffer when available. This development build does not claim gaming-GPU qualification, physical touch certification, console support or complete screen-reader testing. English is implemented; full German, Yoruba and Nigerian Pidgin translations remain in progress.

The four-band reference

(10 × digit 1 + digit 2)
× multiplier = resistance in Ω

Multiplier: black ×1, brown ×10, red ×100, then one extra power of ten per colour. Gold ×0.1; silver ×0.01. This game uses red ±2%, gold ±5% and silver ±10% tolerance bands.

Example: yellow · violet · red · gold = 4.7 kΩ ±5%. The nominal tolerance interval is 4.465–4.935 kΩ. That interval describes the code, not a measured component.

Modelled parts are original unbranded axial resistors. The game does not infer wattage, voltage rating or safe circuit use from body size or colour.
