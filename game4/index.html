Controls and mission rules

Focus the arena and use WASD or arrow keys. Hold a direction button for mouse/touch movement. Space pauses; R retries.

Step controls freeze time between commands. Each move uses the same collision engine and advances one unit of travel; Wait advances 0.5 seconds. Switch modes before starting or while paused.

Collect every core before entering the exit. Spark contact consumes a shield. Time and shields are finite; standing still cannot clear a sector. The coordinate map provides a separate command view.

Recovery manifest

Required energy cores

    Extraction gate

    Locked until every core is recovered.

    The rover must physically reach the gate. Collecting the final core alone does not finish the mission.

    Spark lanes

    Orange tracks show the whole patrol range. Stationary junctions remain dangerous. A hit briefly protects against repeated contact, but staying in a spark will deplete the remaining shields.

    Look for clear connected lanes. Taking a shortcut through a spark alcove trades time for risk.

    About this arcade model

    The game uses ground-plane rover movement rendered as an original 3D scene. Walls, moving spark tracks, core pickups and the exit have explicit collision bounds. Swept contacts and hazard-turn subdivision check the space between frames, including pickups crossed during movement.

    Step play changes when simulated time advances. Every command still uses the same movement, collisions, shields, collectibles and deadline. The generated sectors have validated clear routes; this is automated reachability evidence, not 10,000 manual playtests. There is no electrical-safety instruction in the fictional spark mechanic.
