How to sail this voyage
  1. Select a cargo item, select a deck bay, then use Load selected cargo.
  2. Keep fore/aft trim and port/starboard balance within the displayed limits. Use ballast only when it helps.
  3. Launch with every cargo item loaded. Complete the water trial to unlock the next voyage.

All commands work with mouse, touch, or keyboard. Tab to a labelled control; use Enter or Space to activate it. On the scene, use arrow keys to select a bay, Enter to load, and Backspace to unload. Space pauses a running trial.

About the water trial

This simplified rectangular-hull model uses tonnes, metres and seconds. Sealed ballast tanks, cargo height, water density, wind, waves and fore/aft moments affect stability. It omits structural flex, leaks, free-surface slosh and moving cargo. It is an original teaching game inspired by Genesis 6–9, not a reconstruction of the biblical vessel or a seaworthiness tool.
