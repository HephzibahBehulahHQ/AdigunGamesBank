How to commission this board
  1. Select a load and a branch, then Connect selected load.
  2. Fit a breaker on every branch. Its rating must cover the planned current and stay within the cable limit. Stock and credits are finite.
  3. Run all three operating profiles. A trip must be isolated, reset and corrected before trying again.

Use Tab, Enter and the labelled controls throughout. On the 3D cabinet, left/right selects a branch and Enter connects the selected load. No time limit applies while planning.

      What the electrical model includes

      Each load draws I = P ÷ V at the stated DC voltage. Branch currents are added for each operating profile. A breaker above the branch cable limit fails inspection; current above a fitted breaker's rating trips the test immediately. Real breakers have time-current curves: this game uses an ideal instantaneous threshold.

      The model omits cable resistance, voltage drop, temperature, short-circuit capacity, earthing and shock protection. Its 12–48 V scenarios are original puzzles, not wiring instructions or a compliance assessment for a real installation.
